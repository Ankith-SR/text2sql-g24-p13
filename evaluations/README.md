# EVALUATIONS

Everything here is generated by scripts; do not edit numbers by hand.

| Path | Produced by | Contents |
|---|---|---|
| `results_summary.md` / `.csv` | `python scripts/summarize_results.py` | One row per run: EX, validity, EX by difficulty, latency, model calls |
| `runs/<run>/metrics.json`, `run_record.json` | same | Copies of each run's metrics and full config (model, seed, git SHA, hardware) |
| `figures/` | same | `ex_by_system.png`, `ex_by_difficulty.png` (used in the slides) |
| `error_analysis/<run>/` | `python scripts/error_analysis.py --run runs/<run>` | `errors.csv` (every wrong prediction, auto label + human label column), `error_counts.json` |
| `official/` | `scripts/export_official.py` + official Spider scripts | EM / test-suite accuracy output, pasted as text |

## Metrics (see docs/EVALUATION.md)
- **EX** execution accuracy: predicted SQL returns the same rows as the gold SQL (order only if gold has ORDER BY).
- **Validity**: share of predictions that execute without error.
- **EX by difficulty**: Spider easy / medium / hard / extra, computed with `evaluation/hardness.py`.
- **Latency / model calls**: seconds and LLM calls per question (cost of N and R).
- **Selection stats** (pipeline): how often each tie-break rule decided, how many repairs were used.

## Reproduce
```bash
make heuristic baselines pipeline ablations
python scripts/error_analysis.py --run runs/llm-spider-qwen2.5-coder_7b
make summary
```
